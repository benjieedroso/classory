# Learn.md

## AI Agent Rules

- **DO NOT edit files at all costs.** No exceptions.
- Do not create, modify, or delete any files unless the user explicitly and specifically asks you to do so in the current message.
- When the user asks "why" something doesn't work or describes a problem, explain the cause — do NOT fix it.
- If you think a change is needed, describe what you would change and ask for permission.
- Even if the user's request seems like an implicit request to edit, DO NOT edit. Always ask first.
- This rule applies to ALL files: code, config, documentation, everything.
